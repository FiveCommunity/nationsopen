## Sobre o projeto

O **Nations Open** é um repositório de scripts open source para FiveM, disponibilizado pela **Five Community** com o objetivo de compartilhar recursos com a comunidade de desenvolvedores.

A proposta é permitir que outros desenvolvedores possam estudar, modificar, adaptar e contribuir com os projetos, incentivando o desenvolvimento e a evolução da comunidade FiveM.

## Scripts disponíveis

| Script | Descrição |
|---|---|
| `nation_creator` | Sistema de criação de personagens |
| `nation_skinshop` | Sistema de roupas e personalização |
| `nation_barbershop` | Sistema de barbearia |
| `nation_tattoos` | Sistema de tatuagens |
| `nation_bennys_org` | Sistema de customização de veículos |

Os arquivos estão disponíveis para download diretamente neste repositório.

## Instalação

1. Faça o download ou clone o repositório.
2. Extraia o arquivo do script desejado.
3. Coloque a pasta do recurso no diretório `resources` do seu servidor FiveM.
4. Configure as dependências e os arquivos necessários de acordo com sua base.
5. Adicione o recurso ao `server.cfg`.

Exemplo:

```cfg
ensure nation_creator
ensure nation_skinshop
ensure nation_barbershop
ensure nation_tattoos
ensure nation_bennys_org
```

**Atenção:** verifique as dependências e a compatibilidade de cada recurso antes de utilizá-lo em produção. Alguns scripts podem precisar de adaptações.
